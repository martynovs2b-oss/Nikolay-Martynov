# Матрица по табакам (изи ультра)

Источник: Google Drive — «Матрица по табакам изи ультра.xlsx»
https://docs.google.com/spreadsheets/d/14WGC_TuPPGGb0GWI01RHwIzlmoL4Wb2B/edit
Снимок от 06.10.2026, дата обновления в самой таблице — 3.10.

Данные: [`tobacco_matrix.csv`](tobacco_matrix.csv) — одна строка на вкус.

## Шапка таблицы
- Наличие: уголь — 19.5, мундштук — 5.5 (как в таблице, единицы не указаны)

## Колонки
| Колонка | Смысл |
|---|---|
| `brand` | Бренд (блок в таблице). Сарма встречается дважды — второй блок помечен «Сарма (блок 2)» |
| `flavor` | Аромат. `(без названия)` — строка без имени, но с отметками |
| `level_g` | Колонка 150 / 100 / 50 / 0, в которой стоит «X» (остаток в граммах, 0 — закончился). `100\|0` — отметка в двух колонках сразу, пусто — отметки нет |
| `status` | Роль в матрице: `база` — держим всегда, `заменяемый` — можно заменить другим вкусом, `отказ` — больше не закупаем, пусто — не указано |

## Прочие листы
- «Поставка» — пустой шаблон: Дата, Кто привез, Вес обычка, Вес прем (сигар), Уголь / Мундштук, Сумма
- «Лист1», «Лист2» — пустые

## Особенности исходника (оставлены как есть)
- Опечатки: «зменяемый», «заменчммый», «бза», «ба» (Сарма, без названия), «C» вместо «X» у барбариса (Trofimov TERROR)
- 3 позиции с отметкой в двух колонках: Кокосовые сливки (Jent cigar), Beac peach (Joy), Арбуз (Musthave)
